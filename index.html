      How to play

      One box. One digit. No mouse required.

      Read the sheet

      Every box is already on the sheet. The glowing box is your box. Written methods fill from the right; a whole answer fills from the left. The cursor stops at every small box: type the carry, the amount left over in short division, or 1 to exchange a ten in subtraction. Type 0 if there is none; a 0 is not written on the sheet. In subtraction the top digits you exchange are crossed out. A remainder goes after R; an answer below zero starts with −.

      Fix it and finish

      A wrong digit shows you why and what the box needs. Fix it to keep going. The problem still gets finished, but it does not count as a clean round.

      Learn, then test

      Each year starts with guided learning, one box at a time. Once enough rounds in a row are clean, that year's test starts by itself: every box is open, you move with the arrow keys (Tab follows the method), type to fill, Backspace to clear, and press Enter to hand in. Only the answer is marked; small boxes are for your working. A wrong answer shows the proper answer and working, then the next problem.

      Year checks

      Set the school year from 1 to 7 with the arrow keys. Every area starts there, and each year is pitched for a strong pupil in that year. Learning and the test each need clean rounds in a row: 10 when rounds are short, 5 for medium ones, 3 for long multiplication and long division. Passing the test moves only that area up a year, so one area can run ahead of the others. A round with a fix sends the count back to zero. Passed checks, the clean count and the round in progress are saved on this device, so the game can be closed and picks up where it stopped.
